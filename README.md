# 화장품 제형 분해도

여러 화장품 제형 처방을 상(phase)별로 분해하고, 투입 순서·온도·교반에 따라 제형 구조가 어떻게 만들어지는지 3D와 공정 화면으로 보여 주는 웹 페이지입니다.


- 제품 추가: 전성분이나 특허·논문 본문을 넣고 "분석 프롬프트 복사" → ChatGPT·Claude 등에 붙여넣기 → 답변을 다시 붙여넣으면 같은 형식의 분해도가 만들어집니다.
- 직접 분석한 결과는 각자의 브라우저에만 저장됩니다. 백업 내보내기·가져오기로 옮길 수 있습니다.
